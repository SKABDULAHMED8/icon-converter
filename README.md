# Icon Converter

Convert PNG, JPG, WEBP, HEIC, GIF, TIFF, BMP, SVG or ICO images into Windows `.ico` files. Everything runs in your browser and works offline. Nothing is uploaded.

**Use it online:** https://skabdulahmed8.github.io/icon-converter/

Features: crop, rotate and flip; icon sizes 16 to 512; rounded corners; background color; BMP 4/8/24/32-bit or PNG; dithering; an icon viewer.

## Windows app
Download [IconConverter.zip](IconConverter.zip), unzip it and run `Install.cmd`. Then type `iconconv` in CMD or PowerShell. The app adds save-to-folder (paste a path or pick one) and an optional shortcut that uses the icon.

## Phone
Open the link above in Chrome and choose Install app. It downloads the `.ico` to your phone.
